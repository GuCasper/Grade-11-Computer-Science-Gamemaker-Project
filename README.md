# Vending Machine Simulator

A 2D game built in GameMaker as a group project for my Grade 11 Computer Science course (ICS3U) in 2026.

Play it here on Itch: https://bakedbeans76.itch.io/vending-machine-sim

## About the Game
Low effort visual novel designed to be slapstick comedy.
Contains bad monologing and an overview on the current world of AI by someone who is very much not qualified to speak about so.

## Features
- Voice acting by our talented group member, Ryan Paul
- Maybe three thousand words of text, if you look closely
- Pixelated portraits of the group members as character sprites in horrific and normal poses

## My Role
This was a team project of 3 students. I was responsible for all of the code and some visual design. I learned the basics of the Gamemaker engine using this project, and coordinated the rest of my group members to finish the assets.

## How to Run
1. Install [GameMaker](https://gamemaker.io/) (free version works).
2. Download v1.yymps from this repository.
3. In GameMaker, choose *Import Project* and select the file.
4. Press *Run* (F5).
